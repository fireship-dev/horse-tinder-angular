# HorseTinder

- Use pnpm for package management and scripts.
- Keep the application on AngularJS 1.5.8. A framework migration is a separate task.
- Keep matching and discovery logic in `js/matching.js`; controllers coordinate the UI.
- Validate saved state and swipe inputs before applying them.
- Add regression coverage when changing discovery, swipes, or matching behavior.
- Profiles are fictional fixtures. A match requires a like from both sides.
- Run `pnpm test` and `pnpm build` before submitting changes.
- Preserve photo attribution in `CREDITS.md` and `credits.html`.
- Never commit credentials or local environment files.
